// turbo-all
1. **Reproduce**: Identify the bug and try to reproduce it locally.
2. **Analyze**: Find the root cause in the code.
3. **Plan**: Propose a fix in the chat or an `implementation_plan.md` if complex.
4. **Fix**: Apply the code changes.
5. **Verify**: Confirm the bug is resolved and no regressions were introduced.
6. **Walkthrough**: Document the fix in a `walkthrough.md`.
