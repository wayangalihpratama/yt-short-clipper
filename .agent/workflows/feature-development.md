// turbo-all
1. **Research**: Understand the requirements and existing codebase related to the feature.
2. **Plan**: Create an `implementation_plan.md` in the brain directory.
3. **Approval**: Use `notify_user` to get approval for the plan.
4. **Implement**: Write the code across the necessary files (GUI, core logic, utils).
5. **Verify**: Run the application and verify the new functionality manually or with a script.
6. **Document**: Update `GEMINI.md` if the architecture or tech stack changes.
7. **Walkthrough**: Create a `walkthrough.md` to show the results.
